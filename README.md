An interactive, end-to-end **Power BI Dashboard** designed to analyze bank loan performance, track lending metrics, assess default risks, and evaluate portfolio health.

---

## 📌 Project Overview

This project provides a comprehensive financial analytics solution to help banking executives and risk managers monitor key lending KPIs, understand borrower demographics, and distinguish between **Good Loans** and **Bad Loans (NPLs)**.

### **Key Business Questions Addressed:**
* What is the overall health and profitability of the loan portfolio?
* How are key metrics (Applications, Funded Amount, Received Amount) trending month-over-month?
* What proportion of loans fall under "Good Loans" vs. "Bad Loans"?
* How do loan performance and default rates vary across states, terms, and borrower employment lengths?

---

## 📊 Key Performance Indicators (KPIs)

The dashboard tracks and visualizes primary lending metrics:

| Metric | Description |
| :--- | :--- |
| **Total Loan Applications** | Total number of applications received and processed |
| **Total Funded Amount** | Total capital disbursed as loans |
| **Total Amount Received** | Total payments collected (Principal + Interest) |
| **Average Interest Rate** | Weighted average interest rate across disbursed loans |
| **Average DTI** | Debt-to-Income ratio to assess borrower repayment capacity |
